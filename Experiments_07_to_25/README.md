# MATLAB Experiments 7–25

This folder contains one Word document and one standalone MATLAB script per experiment, organized from 7 through 25. The attached screenshots provide experiment requirements and procedures, not source MATLAB code or the numerical input tables. Example values are marked in the scripts and should be replaced by the assigned values when available.

## Run all scripts

Download this folder or its ZIP archive, extract it, and run `MATLAB_Scripts/Run_Experiments_07_to_25.m` in MATLAB. Each experiment script creates and saves its figure as `Experiment_XX_output.png`. Hardware experiments 15–18 require the DSP board and Code Composer Studio for real hardware measurements; Experiment 17 uses a simulated acquired waveform until connected to the kit.
